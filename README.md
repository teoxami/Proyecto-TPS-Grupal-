# Proyecto-TPS-Grupal-
Sistema TPS desarrollado en lenguaje C para la gestión de una panadería, que permite administrar productos, inventario, ventas y caja en tiempo real.
Simula un punto de venta (POS) con cálculo automático de IVA, generación de tickets y control de stock.
Proyecto académico enfocado en la aplicación de sistemas de información y programación estructurada.
## 📌 Características principales

- 📦 **Gestión de productos**
  - Registrar productos
  - Eliminar productos
  - Modificar precios
  - Listar y ordenar productos alfabéticamente
- 📊 **Control de inventario**
  - Ajuste de stock
  - Advertencia automática de stock bajo
- 💰 **Sistema de ventas**
  - Registro de ventas
  - Selección de IVA (0%, 12%, 15%)
  - Generación de ticket de compra
- 🧮 **Caja**
  - Apertura y cierre de caja
  - Control del total recaudado y número de ventas
- 📈 **Reportes**
  - Reporte general
  - Reporte de productos con stock bajo
- 💾 **Persistencia de datos**
  - Inventario guardado en archivo `inventario.txt`
